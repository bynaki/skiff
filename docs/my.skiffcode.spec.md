# Skiff Code

독립된 앱으로 만든다.
코드 뷰어이자 에디터이다. (파이썬, 자바스크립트, 마크다운 등)
이앱 이름은 `Skiff Code` 이다.
`veiwer` 기능, `editor` 기능, `diff` 기능을 구현할 것이다.
`veiwer`: 코드 읽기 전용 뷰
`editor`: 코드 에디터
`diff`: 깃의 diff와 같은 변경이력 diff
각각은 레이어 형태로 존재해 빠르게 전환할 수 있다.
WebView 위에 CodeMirror6로 레이어를 만든다.
원격 지원 ssh 프로토콜 사용.
프로젝트 단위로 관리된다. (폴더 단위, 아니면 git scope 단위)

## 앱 외부 요청으로 파일 오픈 방법

앱 외부에서 인테트로 받아 실행된다.
요청된 파일이 로컬인지 원격인지에 따라 실행 메커니즘이 다르다.
파일 단위로 열때와 프로젝트 단위로 열때 기능 차이가 있다.
파일 단위:  git 기능과 lsp 기능이 없다.
프로젝트 단위: git, lsp 로 할수 있는 기능을 포함한다.

#### 공통

- `skiffcode://user.host?port=22&path=/Users/username/projects/demo/filename.md` 같은 커스텀 스킴이나 웹 URL(앱링크) 형태의 URI를 인텐트로 받아 실행된다.
- uri 포맷 형식은 (로컬형식과 원격형식을 혼용할 수 있게) AI 에이전트가 정하게 한다. (구현 할때)
- `skiff` 은 파일 정보를 uri 인텐트에 담아 `skiff code`에 전송함으로 실행하게한다.
- 기타 다른 앱에서도 (기본으로 `skiff`가) 이 형태의 uri 링크를 활용해 `skiff code`를 띠울수 있는지 알아본다.

#### 로컬 파일

- 로컬 파일이면 파일 단위로 오픈

#### 원격 파일

- 원격 파일이면 ssh 프로토콜을 이용해 불러온다.
- 저장 되어 있는 프로젝트에 속한 파일이면 그 프로젝트를 활성화 하고 파일을 연다.
- 새 프로젝트를 생성할 수 있는 파일인지 결정은 git이 관리하는 스코프안에 파일인지 아닌지가 결정한다.
- 저장된 프로젝트에 속한 파일이 아니면, 프로젝트에 속할수 있는 파일인지 먼저 검색후 (git이 관리하는 스코프안에 있는 파일인지) 단일 파일로  열지, 아니면 프로젝트를 생성하고 열지 사용자에게 물어본다.
- 이 파일이 프로젝트 안에 속한 파일인지 검색은 사용자 디렉토리 스코프 까지만 검색한다.
- 프로젝트에 속한 파일이 아니면 묻지않고 바로 연다.

## 파일 접근 방법

#### 단일 파일로 접근

- git, lsp 를 활용한 기능들을 사용할 수 없다.
- 로컬 파일이면 무조건 단일 파일로 접근
- 원격 파일이면 원격에 데몬 설치없이 바로 생성하거나 오픈한다.

#### 프로젝트로 접근

- git과 lsp 기능을 활용하기 위한 발판이다.
- 로컬에서는 사용 불가
- 원격 ssh 저장 정보가 필요하다.
- 폴더를 생성하거나 선택하여 프로젝트를 만든다.
- 그 프로젝트가 git이 관리하는 scope 라면 git기능 사용한다.
- 원격에 데몬 설치가 필요하디면 자동 설치 필수
- 프로젝트 단위로 설치하는게 관리하기 쉬운지 데몬하나로 가는게 관리가 쉬운지
- 데몬 자원 관리

## 구현 과제

#### 공통

- 기본은 `skiff` 인텐트로 `skiff code`를 실행하는 방식이다.
- 모든 구현들이 WebView에 붙을 수 있는지 먼저 알아본다.
- 레이어(`viewer`, `editor`, `diff`) CodeMirror6로 구현한다.
- 전송받은 uri가 원격 파일을 가리키고 있다면 `skiff code`는 이미 사용자 원격 정보를 갖고 있어야 되지 않을까? (user, host, port, password 등)
- 모르는 원격 주소이면 바로 열지 않고 사용자에게 열기를 허용할지 묻는다. 추가 정보가 필요하면 사용자에게 묻는다. 저장까지 할지도
- uri에 이미 user, host, port 가 노출되어 있을수 있고 별칭을 사용할 수 있고 `skiff` 와 `skiff code`가 별칭을 공유하고 있다면
- 위의 것이 가능하게 하려면 동기화가 필요하겠군
- 보고있는 파일이 외부에서 변경되면 즉각 실시간으로 반영한다.
- 열린 파일 탐색기능
- 열린 파일들은 자원 정리하지 않고 빠르게 열린 파일 탐색할 수 있게 남겨둔다.
- 너무 자원 소비가 많으면 열린 파일수 제한 두기
- 프로젝트 탐색기능
- git을 사용하여 최근 커밋에서 어디가 변경되었는지 표시기능 (viewer, editor, diff 모두)
- LSP 이용해 할수 있는 기능들 추가
- 테마 적용, 테마는 toml 형식으로 저장
- 사용자 테마 import, export 제공
- 테마는 레이어든 메뉴든 전체 적용

#### 코드 뷰어 (viewer)

- 1등 구현 과제로 스크롤, 확대 축소가 용이하게
- 읽기 전용
- 하이라이팅
- 마크다운파일은 파싱하여 현재 설정된 테마로 보여줌
- LSP 이용해 할수 있는 기능들 추가 (구현 영역으로 이동 등)
- git 기능 (변경이력 라인 넘버 옆에 작은 세로줄로 표시)

#### 코드 에디터 (editor)

- 하이라이팅
- 여느 코드 에디터의 기본적인 설정 제공 (폰트, 폰트 크기, 테마 선택, Tab 크기 등)
- 설정은 toml 형식으로 저장
- 설정 export, import 제공
- LSP 이용해 할수 있는 기능들 추가
- git 기능 (변경이력 라인 넘버 옆에 작은 세로줄로 표시)

#### diff

- 다른 파일과 비교가 아니라, git의 이력 변경 비교이다.
- 창 내에서 수정 전/후 라인을 +, - 기호와 색상(초록/빨강)으로 직접 대조해 보여주는 뷰이다.
- 1등 구현 과제로 스크롤, 확대 축소가 용이하게
- 읽기 전용
- 하이라이팅
