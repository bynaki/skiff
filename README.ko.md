# Skiff

*[English](README.md) · 한국어*

안드로이드용 SSH 파일 매니저. 폰과 서버를 나란히 놓고 탐색하며, 그 사이로 파일을 옮깁니다.

**서버에는 아무것도 설치하지 않습니다.** Skiff는 모든 OpenSSH 설치에 이미 들어 있는 SFTP
서브시스템만 사용합니다. 에이전트도, 헬퍼 바이너리도, 셸 명령도 쓰지 않습니다 — 복사와 삭제의
디렉토리 재귀는 전부 폰에서 처리합니다. 덕분에 셸 없이 `internal-sftp`로 묶인 계정에서도
그대로 동작합니다.

> 초기 버전(0.1.0)입니다. 인증은 비밀번호만 지원하고, 미리보기 뷰어는 아직 없습니다.
> [현재 상태](#현재-상태)를 참고하세요.

## 기능

- **탐색** — 기기와 여러 대의 SSH 서버를. 서버마다 시작 디렉토리를 따로 저장합니다.
- **화면 분할** — 필요할 때만. 기본은 전체화면 단일 패널이고, 사용자가 분할을 켜고 좌우/상하
  방향을 고른 뒤 경계선을 끌어 비율을 맞춥니다. 두 패널이 각자 소스를 고르므로 기기↔서버는
  물론 서버↔서버도 똑같이 나란히 놓을 수 있습니다.
- **파일 전송** — 모든 방향으로, 서버에서 서버로도. 진행률 알림과 함께 포그라운드 서비스에서
  돌기 때문에 앱을 벗어나도 큰 업로드가 끊기지 않습니다.
- **파일 조작** — 새 폴더, 새 파일, 이름 바꾸기, 삭제(재귀), 속성 보기.
- **정렬** — 이름·크기·날짜 기준. 숨김 파일 표시 전환.
- **호스트 키 검증** — 첫 접속 시 지문을 확인합니다. `ssh`와 `ssh-keygen`이 출력하는 것과
  같은 SHA256 형식이라 터미널에 뜨는 값과 그대로 대조할 수 있습니다. 키가 바뀌면 조용히
  받아들이지 않고 눈에 띄게 경고합니다.
- **한국어와 영어** — 시스템 언어를 따릅니다.

## 요구 사항

- 안드로이드 11(API 30) 이상
- SFTP 서브시스템이 켜진 OpenSSH 서버 — **기본값입니다.** 그 외에는 아무것도 필요 없습니다.

## 빌드

JDK 17과 Android SDK가 필요합니다. `local.properties`에 SDK 경로를 지정합니다:

```properties
sdk.dir=/path/to/android-sdk
```

그다음:

```bash
./gradlew :app:assembleDebug     # 빌드
./gradlew :app:installDebug      # 연결된 기기에 설치
./gradlew :app:testDebugUnitTest # 테스트
```

테스트에는 프로세스 안에서 뜨는 Apache MINA SSH 서버가 포함돼 있습니다. 즉 SFTP 코드가 목
객체가 아니라 **실제 서버를 상대로 실제 소켓 위에서** 검증됩니다.

## 권한과 그 이유

파일 매니저는 요구하는 권한이 많습니다. 각각이 왜 필요한지 밝혀둡니다:

| 권한 | 이유 |
|---|---|
| `INTERNET` | 서버 접속. |
| `ACCESS_LOCAL_NETWORK` | 안드로이드 17부터 사설 IP 대역 접근을 따로 통제합니다. 이 권한이 없으면 같은 LAN에 있는 서버로의 연결이 거부가 아니라 **조용히 버려져서** 타임아웃처럼 보입니다. Skiff는 여는 서버가 실제로 로컬 주소일 때만 이 권한을 요청합니다. |
| `MANAGE_EXTERNAL_STORAGE` | 기기의 임의 파일을 탐색·이동·삭제하기 위해. Scoped storage로는 표현할 수 없습니다 — 파일 매니저는 트리 전체를 봐야 합니다. |
| `FOREGROUND_SERVICE_DATA_SYNC` | 앱이 앞에 없을 때도 전송을 이어가기 위해. |
| `POST_NOTIFICATIONS` | 전송 진행률 알림. |

서버 비밀번호는 **Android Keystore 밖으로 나가지 않는 키**로 암호화되며, 메모리에 들고 있지
않고 연결할 때마다 복호화합니다. 호스트 키는 첫 접속 때 저장하고 이후 매 접속마다 검사합니다.

## 현재 상태

동작하고 실제로 쓰고 있지만 아직 어립니다. 없는 것들:

- **미리보기 뷰어** (코드·마크다운) — 다음에 만들 기능입니다.
- **키 기반 인증과 keyboard-interactive 인증.** 지금은 비밀번호만.
- **전송 충돌 선택지.** 반대편에 같은 이름이 있으면 지금은 항상 둘 다 유지합니다
  (`file (1).txt`). 덮어쓰기와 건너뛰기는 엔진에 구현돼 있지만 아직 UI에서 도달할 수 없습니다.
- 검색, 패널 간 드래그 앤 드롭, 압축 해제.

다음 작업은 `docs/`에 앱마다 spec과 plan으로 나눠 자세히 적어뒀습니다. 아키텍처와 기여 안내는 `AGENTS.md`에 있습니다.
